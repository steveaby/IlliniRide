# Documentation

This folder contains the project proposal, database design documents, Stage 3
implementation notes, and Stage 4 database-program SQL.

Important files:

- `stage1_proposal.md`: original project proposal.
- `stage2_database_design.md`: conceptual and logical schema design.
- `Database Design.md`: Stage 3 database implementation and indexing writeup.
- `stage4_advanced_database_programs.sql`: required Stage 4 SQL for constraints, transaction, stored procedure, and trigger.
- `stage4_project_report.md`: Stage 4 project reflection report.

The final reflection report is included in this folder as Markdown.
