## Project Summary

IlliniRide is a campus carpooling web application built for the UIUC community. Commuting from campus to cities like Chicago, O'Hare (ORD), or other Midwest destinations is a recurring challenge for students and faculty. Public transit is limited and solo rideshares are expensive for longer routes. IlliniRide connects drivers heading out of campus with riders going the same direction, letting them split the cost and make the trip together.

Drivers can post rides with their vehicle details, origin, destination, departure time, and price per seat. Riders can browse available rides, filter by date, destination, and price, check seat availability, and instantly book seats. A dynamic price suggestion feature helps drivers set a fair price by computing the distance between cities using coordinates stored in the database and applying a base rate formula.
